## GitHub User Finder

## Автор
Камалов Алексей Ильдарович

## Описание
Графическое приложение для поиска пользователей на платформе GitHub. Позволяет находить профили по логину и добавлять их в локальный список избранного.

## Технологии
*   **Язык:** Python 3.x.
*   **Интерфейс:** Tkinter (стандартная библиотека).
*   **API:** GitHub REST API (https://docs.github.com/en/rest).
*   **Хранение данных:** JSON (локальный файл `favorites.json`).

## Установка и запуск
1.  Убедитесь, что у вас установлен Python 3.
2.  Установите библиотеку `requests`:
    ```
    pip install requests
    ```
3.  Запустите приложение:
    ```
    python main.py
    ```

## Использование API
Приложение использует публичный эндпоинт GitHub API: `GET /users/{username}`.
Для анонимных запросов действует лимит: **60 запросов в час**.
Для увеличения лимитов требуется аутентификация через токен.

## Использование программы
1.  Введите логин пользователя GitHub в поле ввода (например, `torvalds` или `octocat`).
2.  Нажмите кнопку **«Поиск»**.
3.  Если пользователь найден, его имя и логин появятся в списке.
4.  Нажмите кнопку **«Добавить в избранное»**, чтобы сохранить профиль.
5.  Избранные пользователи сохраняются в файл `favorites.json`.

## Примеры использования (тесты)
1.  **Успешный поиск:** Введите `defunkt`. В списке отобразится информация о пользователе Chris Wanstrath.
2.  **Поиск несуществующего пользователя:** Введите `asdfghjkl12345`. Должно появиться окно с ошибкой «Пользователь не найден».
3.  **Пустое поле поиска:** Нажмите «Поиск», не вводя логин. Должно появиться предупреждение «Поле поиска не должно быть пустым!».
4.  **Добавление в избранное:** Найдите пользователя и добавьте его. Затем найдите его снова и попробуйте добавить еще раз — должно появиться сообщение «Пользователь уже в избранном!».
